# LeadPilot — Sales & CRM System

Professional CRM and sales management dashboard built with React and Vite.

## Features

- Dashboard with pipeline value, win rate, overdue tasks
- Leads CRUD with sources, priorities, CSV export
- Contacts and Companies management
- Drag-and-drop sales pipeline
- Deals management with stages and CSV export
- Tasks and follow-ups with overdue highlighting
- Team performance tracking
- Reports and settings
- Light/dark themes
- LocalStorage persistence
- Fully responsive

## Quick Start

```bash
npm install
npm run dev
```

## Tech Stack

React 18, Vite, React Router, Lucide React, Recharts, custom CSS, LocalStorage
